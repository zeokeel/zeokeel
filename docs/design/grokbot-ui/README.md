## 重新生成

```bash
cd docs/design/grokbot-ui
python3 render_mockups.py        # 依赖 Pillow + Noto Sans CJK SC
```

## 明确没有画的东西

- 没有任何"统计仪表盘 / 装饰面板 / 进度百分比"（§14 明确不做）。
- 没有"全部允许"按钮、没有批量审批。
- 微信里没有按钮：审批靠回一句「同意 / 不同意」；手机端不是简化页，而是同一套全功能 Web（内网直连）。
- 没有真实后端：`/inbox`、`/team` 的数量都是写死的。

## 落到真实实现时的映射

| 原型元素 | 真实实现 |
|---|---|
| 任务卡 | antd `Card` + 自定义三行布局（不要用 `Table`，三行制不是表格） |
| 审批卡 | antd `Card` + 三按钮；动词不可中性化；Esc=拒绝 |
| 路由表 | antd `Table`（类别/渠道/免打扰/升级） |
| 连接器状态 | antd `Descriptions` + `Tag` |
| 开关 | antd `Switch`（原型里是手绘的） |
| 状态色 | 只从 `tokens.css` 取；进行中不用警告色 |
| 图标 | `internal/icons` 生成物，不手绘 |

真实实现还要遵守 AGENTS.md 的 Web 规则：颜色/字号/间距只来自 token、官方件优先、协议只经 `web/src/api/`。

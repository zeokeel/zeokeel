# A4 interaction QA — 场景文件（interaction-drive.txt）
#
# 由 docs/research/redesign-2026-11/A4-qa/testdata/a4qa 解释执行：它用与
# internal/devtools/ui-drive 相同的 boot（真 desktop assembly + uiroot + 脚本化
# OpenAI 兼容流），逐条跑下面的 case，输出 PASS / FAIL / EXPECTED-FAIL。
#
# 语法
#   case <id> | <surface> | <标题> | open|guarded
#     open    = 必须通过；失败即回归
#     guarded = A4 审计已确认"当前缺失、实现中"；现在应为 EXPECTED-FAIL，
#               实现落地后自动变成 PASS(fixed)（这一列就是收尾看板）
#   boot idle|session            启动产品；session = 建工作区+1 个会话
#   session <标题>               再建一个会话（成为当前会话）
#   run-slow                     发一条慢速消息，等 Running
#   approval <工具>|<摘要>       让审批服务挂起一条真实待审批
#   key <chord>                  Esc/Tab/Enter/Down/Up/Home/End/PageDown/Cmd+K/Cmd+Comma/Cmd+F/Cmd+Alt+P/...
#   tab-to <标签> / tab-to-any a|b   Tab 直到焦点落在该无障碍名（可给改名别名）
#   click-any a|b / expect-focus-any a|b  标签改名时的别名写法
#   type <文本> / click <标签> / hover <标签> / advance <毫秒> / snapshot <名>
#   wait-text / expect-text / expect-no-text / expect-tooltip
#   expect-focus / expect-running / expect-sessions / expect-sessions-delta
#   expect-settings / expect-palette / expect-pending / expect-disabled
#   expect-tab-order a|b|c        一次 Tab 走查里这些标签按序出现
#   expect-hover-selected-distinct <当前行>|<另一行>    像素：选中比 hover 更浓的品牌 tint
#   expect-palette-all-commands   每条已注册命令都能按自己的标题检索到
#   expect-drop-taken             composer 上有元素级 drop zone 接管拖入
#   expect-control-name <子串>    屏上存在名含该子串的控件
#   expect-reason <标签>|<子串>   禁用/不可用控件有可读原因（可见或 hover 后出现）
#   expect-left-of <左标签>|<右标签>  两个文案在同一行且左者更靠左（旁注在发送按钮左侧）
#   expect-tree-selected <名>     树里该行是当前项
#
# 文案定稿（Lead，2026-11-18）：
#   禁用发送的旁注（12/18 tertiary，composer 工具条右侧、发送按钮左侧，只显示与当下相关的一条）：
#     · 未配置模型/密钥 →「先配置模型」（可点，打开模型设置）
#     · 审批待处理     →「处理审批后可发送」
#     · 输入为空       → 不显示（placeholder 已表达）
#     禁用控件本身不挂 Tooltip。
#   文件页返回：面包屑根节点「工作区根目录」，Label("返回工作区根目录")，点击/Enter 回到文件树（不关文件页签）。
#   case 里的其它界面文案以 zh 为准；实现者可改文案，但要同步本文件。
# 基线：HEAD e9a0d6b（本次套件首次全量运行见 A4-QA-REPORT.md §2）。

## 4. 剩余项：非 SDK 或明确边界（不阻塞）

- **非 SDK（仍留产品仓）**：`old/internal` 的 shell(25.2k)、session(8.8k)、store(5.9k)、app(8.2k)、
  acp、globalhotkey、importer、updater、prompt、state、workspacechanges、sessionreference、
  memory 抽取/整合、modelcatalog、presets、i18n/design/brand/icons 等 —— 见 `02-sdk-gaps.md` §3，
  这些不是"SDK 缺口"，需要产品层实现（Rig 只提供契约）。
- **SDK 侧可选小改进**（不属于原 12 项）：
  - `gate.Review` 的拒绝原因目前只经 `ReviewOutcome`/observer 暴露，agent 的工具错误文本仍是固定 deny
    文案（CHANGELOG v0.13 Notes 已记录）；如模型需要看到原因，可加 `Decision` reason 通道。
  - MCP 仍不做 OAuth（用 `Headers`/`HTTPClient` 自行注入）；不做 server→client 请求（sampling/elicitation/roots）。
  - LSP 仍不支持 completion/rename/code actions/formatting/workspace folders（只读工具集边界，doc 已写明）。
  - Compaction 的持久化替换要求产品 `History` 实现 `rig.HistoryReplacer`（`session.Memory` 已实现；
    SQLite 产品实现需要补）。
  - `CheckpointStore` 没有 SDK 默认实现（内存/文件实现由产品提供，接口已有）。
  - 预设只覆盖 minimal/standard/all；旧产品 Creator 的设置工具属产品层。

> 对应文档：[FIELD-DESIGN.md](FIELD-DESIGN.md)（字段/说明文字规范）、[INTERACTION.md](INTERACTION.md)（第二轮的 P0 清单）。

## 1. 为什么先修这一块

真实用户 90% 的时间只碰两个东西：**输入框**和**设置里的那一行**。这两处在第一/二轮里同时犯了同一个错误——**控件与说明文字的位置关系是错的**：

- 输入框：权限/模型/思考三个选择器塞在文本左侧（`Sender.prefix` 228–253px），文本列被推右 250px，且随控件增减漂移 **61.5px**；placeholder 看起来"飘在中间"；发送键是 32px 的图标按钮、无可读名；停止态是同款浅色 spinner。
- 设置：label 与帮助文字挤在一行（13px vs 12px、同字重），一页里同一个词说两遍（"语言 语言…"），数字框恒 90px 无单位，只读页也挂保存栏。

## 2. 改成了什么（可直接对照截图）

### 2.1 输入框：文本在上、工具条在下

| | 之前 | 之后 |
|---|---|---|
| 结构 | `prefix` = `+` + 权限 + 模型 + 思考，与文本同一行 | 文本独占整行；工具条在文本**下方**（左：`+` / 权限 / 模型；右：发送） |
| 文本列起点 | x=537.7（随控件漂移 505.8–567.3） | x=301（卡片左 + 12px），**不再漂移** |
| 空态高度 | 96px（`minRows:2`） | **88px**（`minRows:1`），长草稿 14 行后内滚 |
| 发送/停止 | 32px 图标按钮，读屏名 `arrow-up` / `Stop loading` | **34px** 圆形，`aria-label` 发送 / 停止本轮；停止是**方块 + 墨色实心**，一眼看出可点 |
| 占位文字 | 起点被推右，视觉上"居中" | 与输入文字同起点，左侧对齐 |
| 焦点 | **完全没有**焦点样式 | 2px accent 外环 + 边框变色（`focus-within`） |
| 点卡片空白 | 无反应 | 回到草稿（桌面惯例） |
| 中文输入法 | 组合中按 Enter 会把拼音发出去 | `isComposing` / keyCode 229 直接放行给输入法 |
| 禁用原因 | placeholder 里 1.8:1 的灰字 | 卡片**上方**一条 notice：「本会话有一条审批等待处理：处理后才能继续发送。」，同时隐藏键位提示（避免"Enter 发送"与"Esc 拒绝"同屏打架） |
| 用量行 | 挤在工具条里，和发送键抢位置 | 移到卡片下方：左键位提示、右用量，各自成列 |

### 2.2 审批与停止（同一处的行为修复）

- **只有拥有待审批的那个会话**会被禁用；别的会话、"现在"页不再被别人的审批锁死。
- 停止先调 `run.cancel` 再断本地流 —— 实测停止后立刻再发是 **200**，不再 409。

### 2.3 设置：一条字段的三段式

```
标签 14/22 · 500
  ↕ 4px
控件（数字 128 + 单位内嵌 / 文本 360 / 密钥 480 / 结构化整宽等宽）
  ↕ 4px
帮助 12/18 · 400 · tertiary
字段之间 20px；组之间 24px + 1px 分割线
```

- 帮助从"标签同一行"移到**控件下方**；一节里同名的字段标签自动让位给节标题（视觉隐藏、保留给读屏）——所以"语言 / 语言"只剩一行。
- 数字框带单位（`tokens` / `px` / `s` / `KiB`），右对齐；label 里的"（tokens）"删掉，避免与控件里的单位重复。
- 开关行改成"左名称、右开关"；单选组横向排开；结构化 JSON 字段用等宽、整宽、可拉伸。
- 模型目录：空态一句话（"还没有模型。添加一个之后，输入框的模型选择器才能切换。"）+ 真正的行组件（边框、圆角、左右分区），不再是浏览器默认的项目符号。

## 五、已知且写明的限制（不是待办，是边界）

- **无登录**：M6 的角色是权限策略，不是认证；网关信任本地客户端。任何把它当成认证的用法都是错的。
- **CDP context 不跨浏览器重启**：Bot 重启后仍需重新登录；要跨重启保持登录需要独立 user-data-dir。
- **飞书加密事件不支持**：开启 encrypt 会明确报错（`ErrFeishuBadPayload`），不静默吞掉。
- **飞书 v1 扁平事件**不受理。
- **MCP 注解**（destructiveHint/readOnlyHint）未读取——但所有 `mcp__*` 工具本来就会停审批，
  所以"破坏性工具必停审批"已经由构造满足。
- **headless smoke 的 exit 124 = "起得来且不崩"**，不等于功能正确。
